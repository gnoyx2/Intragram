보안 범위와 주의사항 Security scope and limitations

아직 외부 기관의 독립 보안 감사를 받지 않았습니다. 높은 수준의 보안이 필수인 환경에서는 사용하지 마세요. Intragram has not undergone an independent security audit. Do not rely on it where a failure could put someone at risk.

보호하는 항목What is protected

  • 같은 네트워크의 도청과 사칭:Other LAN devices: 1:1 대화는 종단 간 암호화되며, 6자리 보안 번호를 대조해 중간자 공격을 확인할 수 있습니다.1:1 E2EE, signed peer IDs, and 6-digit security code checks prevent LAN eavesdropping or impersonation.
  • 과도한 연결 요청 제한:Connection rate limits: 완료되지 않은 핸드셰이크는 호스트당 4개(전체 16개), 연결 시도는 10초당 24회로 제한합니다.Limits unauthenticated handshakes to 4 per host (16 total) and 24 connection attempts per 10 seconds.
  • 외부 인터넷 연결 차단:No public internet traffic: 모든 소켓은 사설 IP 대역만 허용하며, QR 코드 인식(zxing2)도 기기 안에서 오프라인으로 처리합니다.Every socket is restricted to private IP ranges, and QR scanning (zxing2) runs offline on the device.
  • 기본 무저장과 파일명 정리:Memory default & safe filenames: 보관소를 켜지 않으면 대화를 디스크에 저장하지 않으며, 받은 파일 이름에서 경로 이동 문자를 제거합니다.Chats stay in memory by default, and incoming filenames are stripped of path traversal sequences.

알아두어야 할 한계Known limitations

  • 그룹 대화방과 방 파일:Group room host & files: 그룹 방은 방을 연 호스트를 거쳐 전달되므로 호스트가 내용을 볼 수 있고, 그룹 방 파일은 평문 전송 후 SHA-256으로 확인합니다.Group rooms route through the host, and group files cross the LAN unencrypted with SHA-256 verification.
  • 구형 HTTP 게스트 포털:Legacy HTTP portal: 호환용 HTTP 포털은 암호화되지 않습니다. 새 앱·웹 연결은 메시지와 파일을 WebRTC로 암호화합니다.The legacy HTTP portal is plaintext. New app-to-web connections encrypt messages and files with WebRTC.
  • 운영체제 캐시와 메모리 복사본:OS swap & picker caches: 앱 버퍼를 덮어쓰거나 즉시 삭제를 실행해도 운영체제 스왑, 키보드 캐시, 파일 선택기 임시 파일까지 지우지는 못합니다.Wiping app memory cannot erase OS swap space, keyboard caches, or temporary files created by system file pickers.
  • 사설 대역 VPN:Private-IP VPN tunnels: 사설 IP 주소를 배정하는 VPN이 켜져 있으면 트래픽이 VPN 터널을 통과할 수 있습니다.If a VPN assigns private RFC 1918 addresses, traffic may travel through that VPN tunnel.
