기기를 찾고 연결하는 과정 How devices find and connect to each other

주변 기기 탐색부터 사설 IP 확인, 암호화 키 교환, 직접 전송까지 네 단계로 연결됩니다. Connections run in four steps across your local network: discovery, private IP check, key exchange, and encrypted transfer.

주변 기기 찾기Local discovery

같은 Wi-Fi에 연결된 Intragram 기기를 자동으로 찾거나 직접 IP·QR로 연결합니다.Automatically finds Intragram devices on the same Wi-Fi, or pairs by local IP and QR scan.

02망 확인Network check

사설 주소만 허용Private IP only

공인 인터넷 주소나 통신사 대역(100.64/10)을 차단해 트래픽이 외부로 나가지 않습니다.Blocks public WAN addresses and carrier CGNAT 100.64/10 so traffic never leaves the LAN.

03보안 검증Verification

암호화 키와 보안 번호Key exchange

양쪽 기기가 직접 세션 키를 맞추고 같은 6자리 보안 번호를 화면에 표시합니다.Devices negotiate session keys directly and show a matching 6-digit security code on both screens.

모든 메시지와 1:1 파일 조각을 순서까지 검증해 암호화 전송하며 위조 시 즉시 차단합니다.Encrypts messages and 1:1 file chunks in strict order, closing the connection if tampering is detected.

집·연구실 공유기 자동 탐색Automatic Wi-Fi discovery

같은 공유기에 연결된 앱을 켜 두면 별도 주소를 입력하지 않아도 주변 목록에 바로 나타납니다.Leave the app open on the same home or lab router and nearby devices appear automatically.

보안 범위와 주의사항 Security scope and limitations

아직 외부 기관의 독립 보안 감사를 받지 않았습니다. 높은 수준의 보안이 필수인 환경에서는 사용하지 마세요. Intragram has not undergone an independent security audit. Do not rely on it where a failure could put someone at risk.

보호하는 항목What is protected

  • 같은 네트워크의 도청과 사칭:Other LAN devices: 1:1 대화는 종단 간 암호화되며, 6자리 보안 번호를 대조해 중간자 공격을 확인할 수 있습니다.1:1 E2EE, signed peer IDs, and 6-digit security code checks prevent LAN eavesdropping or impersonation.
  • 과도한 연결 요청 제한:Connection rate limits: 호스트별 미완료 연결과 반복 시도 횟수를 자동으로 제한해 로컬 망 연결 남용을 줄입니다.Automatically limits incomplete handshakes per host and rapid connection bursts on the local network.
  • 외부 인터넷·추적 요청 없음:No internet or telemetry: 모든 통신은 사설 IP 대역만 허용하고 외부 서버, 분석 도구, 원격 폰트를 불러오지 않으며 QR 인식도 기기 안에서 처리합니다.All sockets allow private IP ranges only, with zero analytics, remote fonts, or cloud calls; QR scanning runs offline.
  • 기본 무저장과 안전한 파일 저장:Memory default & safe filenames: 보관함을 켜지 않으면 대화를 디스크에 쓰지 않으며, 받은 파일 이름의 경로 탈출 문자를 제거합니다.Chats stay in memory by default, and incoming filenames are stripped of path traversal sequences.

알아두어야 할 한계Known limitations

  • 그룹 대화방과 방 파일:Group room host & files: 그룹 방은 방을 연 호스트를 거쳐 전달되며, 그룹 파일은 암호화 없이 같은 망을 통해 전송됩니다(기밀 대화는 1:1 사용).Group rooms route through the host, and group files cross the LAN without E2EE (use 1:1 chat for sensitive files).
  • 구형 HTTP 게스트 포털:Legacy HTTP portal: 구형 호환용 HTTP 포털은 암호화되지 않습니다. 새 앱·웹 연결은 메시지와 파일을 WebRTC로 암호화합니다.The legacy HTTP portal is plaintext. New app-to-web connections encrypt messages and files with WebRTC.
  • 운영체제 캐시와 임시 파일:OS swap & picker caches: 앱 기록을 즉시 지워도 운영체제 스왑, 키보드 자동완성, 파일 선택기 임시 파일까지 지우지는 못합니다.Wiping app memory cannot erase OS swap space, keyboard caches, or temporary files created by system file pickers.
  • 사설 대역 VPN:Private-IP VPN tunnels: 사설 IP 주소를 배정하는 VPN이 켜져 있으면 트래픽이 해당 VPN 터널을 통과할 수 있습니다.If a VPN assigns private RFC 1918 addresses, traffic may travel through that VPN tunnel.
