브라우저 ↔ 브라우저

대화는 여기서 시작해요.

초대 코드를 상대에게 보내고, 상대의 응답 코드를 받아 연결하세요. 이 탭은 계속 열어 두세요.

  1. 내 초대 코드 전달
  2. 상대의 응답 코드 입력
  3. 대화 · 파일 전송

브라우저 ↔ 브라우저

초대받으셨나요?

상대가 만든 초대 코드를 붙여 넣으세요. 응답 코드를 만들어 돌려드리면 연결됩니다.

연결 코드 교환

코드에는 연결 주소와 인증 정보가 담겨 있습니다. 대화할 상대에게만 전달하세요.

응답 코드를 상대에게 보내 주세요. 상대가 입력하면 대화창이 열립니다.

앱 ↔ 브라우저

앱과 암호화해서 연결하세요.

앱의 연결 메뉴에서 ‘암호화 웹 연결’을 열고 초대 코드를 만드세요. 아래에서 참여한 뒤 응답 코드를 앱에 돌려주세요.

  1. 앱에서 암호화 웹 연결 열기
  2. 초대·응답 코드 교환
  3. 양쪽 확인 번호 비교

메시지와 파일은 WebRTC로 암호화됩니다. 두 기기를 같은 네트워크에 연결하고 앱을 열어 두세요.
